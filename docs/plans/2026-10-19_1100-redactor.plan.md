## Notas de ejecución

- **Un task = un commit.** Se añaden rutas concretas, nunca `git add -A`, y se
  muestra el diff antes de cada commit.
- **T5 y T6 son paralelas** y **T7 también**: tocan ficheros distintos.
- **`owner` de T12**: se despachan los revisores solo cuando haya código que
  revisar.
- **T10 no reescribe el histórico**: `CHANGELOG.md` y `docs/audits/` conservan
  las menciones a `hookify.js` porque describen lo que pasó entonces; solo se
  añade entrada nueva y se corrigen las referencias vivas.
